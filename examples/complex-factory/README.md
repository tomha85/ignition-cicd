# Multiple Gateway factory onboarding template

Use lab-assembly as a source-validated example of two Gateway identities:
assembly-main and utilities-main. Each Gateway has its own project roster,
curated config directory, TEST target registration and environment mapping.
Project names may repeat ACROSS factories, but must be unique per Gateway.
No verified PLC tag sources or EAM Agent commissioning are provided.
Before real deployment, independently qualify EAM task/Agent selection,
Gateway rollback, Perspective rendering, alarm behavior and physical signals.
